# 領収ボックス 機能一覧

税理士事務所向けの **AI 領収書・請求書キャプチャ＆記帳 SaaS**。
スマホで撮る → AI がデータ化 → web（事務所）で仕訳・エクスポート。個人（無料/サブスク）と会社（B2B）の両プランに対応。

## 構成（3層）
| 層 | 技術 | 役割 |
|---|---|---|
| モバイル | Tauri v2（Rust + React/TS）, Android | 撮影・経費精算の申請・AI読み取りの訂正 |
| web | React/TS/Vite + Tailwind（共有UIキット `web/src/ui/`） | 受信箱・仕訳・マスタ・エクスポート・顧問先/事務所管理・運営 |
| backend | FastAPI + SQLAlchemy(async) + PostgreSQL(**RLS**) + MinIO + Alembic | マルチテナントAPI・AI連携・課金検証 |

---

## 1. 取込・AI解析
- スマホ撮影（**領収書/請求書モード** の切替）→ AI自動抽出（店名・金額・日付・税区分・インボイス登録番号(T)・摘要）
- **音声メモ**（撮影時に一言）→ STT でメモ化
- web アップロード（画像/PDF・ドラッグ&ドロップ）
- **メール取込**（Gmail連携・自動/手動取込）
- **クレジット明細取込** + 領収書との**網羅チェック（照合）**
- 解析**完了/失敗のプッシュ通知**（FCM）
- 複数画像・PDF複数ページ対応

## 2. 受信箱（web）
- 取込一覧・**画像ビューア**（全画像を並列表示・ズーム・元画像リンク）
- **AI読み取りの訂正**（店名/金額/日付/税区分/摘要/インボイス番号 等）
- **重複検知**（同日+同額+同取引先。カード明細絡みは取引先問わず）・「重複でない」解除
- **統合伝票マージ**（明細+鏡など「1支払いに画像複数」を1件に統合。項目ごとに採用値を選択・可逆「ばらす」）

## 3. 仕訳・元帳（web）
- **仕訳キュー**（未仕訳を記帳）：借方/貸方科目・**補助科目**・取引先・税区分・インボイス番号
- **AIサジェスト**（科目・取引先の自動提案）
- 保留（hold）／付箋
- **元帳**（仕訳済み一覧・直接編集）
- **監査ログ**（訂正・削除・承認・仕訳の履歴＝電子帳簿保存法の訂正削除履歴）
- 締め日による**期間外警告**

## 4. 経費精算（モバイル申請 ＋ web承認）※会社プランのみ
- スタッフがモバイルで**申請**（読み取り訂正・摘要・**経費の目的**の入力・複数まとめて申請）
- 承認者がwebで**承認（＝記帳）／否認（理由付き）**
- **承認・否認後は修正不可**

## 5. マスタ管理（web）
- 勘定科目 ＋ 補助科目
- 取引先 ＋ インボイス登録番号
- 付箋（メモ用タグ）

## 6. エクスポート（web）
- 会計ソフト形式の **CSV**：**freee / 弥生 / MJS-MAS / 汎用**
- 仕訳データ・元帳（期間指定）

## 7. プラン・課金
| プラン | 上限 | 備考 |
|---|---|---|
| free（個人・無料） | **月10枚**（＋全フリー合計 **1日1000枚**） | AIコスト保護のグローバル上限あり |
| pro（個人・サブスク） | **月500枚** | ¥3,000/月・**Google Play IAP** |
| business（会社・B2B） | **上限なし** | 経費精算はこのプランのみ |
- 使用量メーター／購入→**サーバ検証**→pro付与

## 8. アカウント・組織・権限
- **個人**：匿名スタート → メール/パスワード登録（**遅延サインアップ**・端末そのまま）→ ログイン/退会
- **会社**：税理士事務所 ＋ 顧問先（client）＋ 利用者（client user）
- **権限（RBAC・5ロール）**
  | ロール | 説明 |
  |---|---|
  | `firm_owner` | 事務所管理者（職員）：全顧問先・事務所管理 |
  | `firm_staff` | 事務所職員（一般）：担当顧問先のみ |
  | `client_admin` | 顧問先管理者：自社の全データ＋利用者管理 |
  | `client_accountant` | 顧問先経理：自社の全データ閲覧 |
  | `client_user` | 顧問先スタッフ：アプリで経費精算の申請 等 |
- 端末**ペアリング**（QR/セルフQR）・**招待**（メンバー/利用者）

## 9. 連携
- **Gmail**（メール取込）／**Google Drive**／**Gemini**（AI OCR・整形・STT）

## 10. 運営（プラットフォームオペレーター）
- 税理士事務所の**プロビジョニング**・プラン/状態（active/suspended）管理（顧問先データは閲覧しない分離設計）

- backend ルーター：`api/app/routers/`（auth, captures, receipts, journal, expense, masters, export, clients, members, gmail, drive, card_statements, reconcile, billing, individual, pairing, invites, operator, firm, files, devices）
