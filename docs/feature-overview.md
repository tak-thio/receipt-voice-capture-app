# 会計事務所向け 領収書管理システム（仮称） — 特徴まとめ（1枚もの）

> 説明資料用の特徴中心サマリ。製品名は仮。詳細設計は [`saas-design.md`](saas-design.md) / [`architecture.md`](architecture.md) を参照。

**スマホ・メール・アップロードから取り込み、AIが仕訳まで。税理士事務所と顧問先をつなぐクラウド。**

## 1. きめ細かい階層・権限管理（マルチテナント）

「税理士事務所 → 顧問先企業」の2階層を前提に、**6つの役割**で「誰が何を見て・編集・確認できるか」を制御。

| 役割 | 立場 | 主な権限範囲 |
|---|---|---|
| **システム管理者** | 運営 | 事務所アカウントの発行・管理（顧客データには触れない） |
| **会計事務所管理者** | 事務所 | 全顧問先のデータ・事務所設定・職員/AI設定の管理 |
| **会計事務所担当者** | 事務所 | 割り当てられた担当顧問先のみ |
| **顧問先管理者** | 顧問先 | 自社の全データ ＋ 自社ユーザー管理 |
| **顧問先経理担当者** | 顧問先 | 自社の全データの確認・仕訳 |
| **顧問先一般社員** | 顧問先 | 自分が登録した領収書のみ |

→ データは**データベースレベル（行単位のアクセス制御）で完全分離**。事務所間・顧問先間の情報漏えいを構造的に防止。

## 2. 3つの取り込み経路（アップロード元）

- **メール**：顧問先のGmailを連携し、届いた領収書（添付・本文）を自動取り込み
- **アプリ**：スマホで撮影してアップロード
- **手動**：PC・Webから画像／PDFをドラッグ＆ドロップ

## 3. スマホアプリ：音声 ＋ 連続撮影

- 領収書を**自動検出して連続シャッター**（かざすだけで次々撮影）
- 用途を**音声で読み上げ** → 画像＋音声をまとめて送信
- AIが**1回の解析で複数枚・複数明細をまとめて構造化**

## 4. AIによる自動読み取り・自動仕訳（学習する）

- 日付・支払先・金額・**消費税内訳（10%/8%）**・**インボイス番号**・摘要を自動抽出
- 借方／貸方の勘定科目・取引先を**提案**し、**過去の修正を学習して精度が向上**
- **インボイス制度対応**（登録番号で取引先を自動引き当て）
- 読み取れなかったものは「**請求書として認識できませんでした**」と明示し、取りこぼさない

## 5. カード明細の取り込み ＋ 領収書との紐付け

- 領収書だけでなく**クレジットカード利用明細も「1行＝1件」で取り込み**
- 同じ取引（日付・金額）を**自動でまとめて突き合わせ**、**二重計上を防止**

## 6. 確認・承認ワークフロー

- **一般社員（登録者）は承認前に自分の入力を修正可能**（AIの読み取り間違いをその場で訂正）
- 経理・事務所が確認して**確定（仕訳済）**。否認や**付箋（「社長に確認」等）**で社内連携

## 7. 自由なエクスポート

- **freee／弥生／汎用CSV** など、利用中の会計ソフトに合わせて出力
- 期間・形式を選んで元帳・仕訳データを書き出し

## 8. マスタ管理・検索・セキュリティ

- 勘定科目・取引先などのマスタは**事務所の共通テンプレ ＋ 顧問先ごとの上書き**に対応
- 支払先・登録番号などで**全文検索**
- **TLS通信 ＋ WAF（OWASP）／AIキーは暗号化保管／テナント分離はデータベースで強制**
