## 表現の指針(両ストア共通)

### 連携(SaaS)部分の言い回しの肝
- 「**〜が導入している場合は連携できます**」= 条件付き・任意と明示
- 「**個人だけのご利用も可能**」を必ず添える
- 「事務所アカウントが必要」「法人専用」とは**書かない**

### 明記すべき(特にIAP)
- Proプランの価格・枠(¥3,000/月500枚)・**自動更新**・**解約方法**
- アカウント登録なしで試せる導線(個人で始める/匿名開始)/個人で無料登録 ← 本文と実アプリで一致させる

### 避ける(過剰主張・正確性)
- 「**電子帳簿保存法対応**」: 要件(訂正削除履歴=監査ログ等)が実装済みでなければ書かない。
  現状は「整理・保存・共有」までの表現に留める。
- 「税務申告ができる」等、実装していない機能は書かない。
- 「マルチテナント」等の B2B 専門用語は公開面に出さない(法人導入の説明は事務所経由)。

## データセーフティ / プライバシー(申告の下敷き・要清書)

実際のデータフロー(captures / 個人signup / 連携 / FCM / IAP)に基づく収集項目の概略:

| 種類 | 例 | 用途 | 備考 |
|---|---|---|---|
| 個人情報 | メールアドレス・パスワード(個人登録時) | アカウント | 連携(QR)利用時は不要なことも |
| 写真/画像 | 領収書・レシート画像 | アプリ機能(AI読取) | サーバ保存・AI解析 |
| 音声 | 音声メモ | アプリ機能(補足) | 任意 |
| 利用データ | アプリ内操作 | 機能提供 | |
| 端末ID | FCM トークン | プッシュ通知 | |
| 購入 | サブスク購入状態 | 課金管理 | Google Play 経由 |

- 送信は暗号化(HTTPS/TLS)。データはサーバ(クラウド)に保存。個人データは退会で削除可。
- 連携時は、撮影データが連携先(会社/税理士事務所)に共有される旨を明記。
- プライバシーポリシーURL は両ストア必須([[store-submission-demo]] の残タスク)。
