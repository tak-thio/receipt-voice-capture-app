# 社内テスター/初回利用者向けマニュアル

このマニュアルは、Windows PCで領収書入力アプリを起動し、APIキー設定、録音、文字起こし、AI整形、レビュー、辞書追加、CSV出力まで確認するための簡易手順です。

## 1. Windowsでの起動

テスト対象ブランチは `test/windows-local-build` です。Codexに作業させる場合は、[テスター向けCodex指示文](tester-codex-instructions.md) または [短いプロンプト](codex-tester-prompt.md) を使ってください。

手元で直接起動する場合:

```powershell
git clone https://github.com/tak-thio/receipt-voice-capture-app.git
cd receipt-voice-capture-app
git checkout test/windows-local-build
npm install
npm run typecheck
scripts\windows-start.cmd
```

起動しない場合は、次を試してください。

```powershell
npm run app:test
```

## 2. APIキー設定

1. アプリを起動します。
2. 設定画面を開きます。
3. `Gemini APIキー` または `OpenAI APIキー` に実キーを入力します。
4. 保存します。
5. AI診断または接続チェックを実行し、選択中プロバイダーが利用可能になることを確認します。

実APIキーはCodexのチャット、Git、README、docs、設定例、スクリーンショットに残さないでください。

## 3. Gemini/OpenAI利用設定

設定画面で、利用するAIプロバイダーをGeminiまたはOpenAIにします。

確認する項目:

- STTまたは文字起こしがGemini/OpenAI API経由の設定になっている
- OCRがGemini OCRまたは既存の利用可能な設定になっている
- AI整形が選択中プロバイダーを使う設定になっている
- 診断表示が未設定やエラーではなく、利用可能な状態になっている

今回の社内テストでは、ローカルSTT用のPython/faster-whisperやTesseractなどの追加インストールは必須ではありません。まずGeminiまたはOpenAI API経由で確認してください。

## 4. 録音

1. 入力画面を開きます。
2. Windowsのマイク許可が出た場合は許可します。
3. 録音開始を押します。
4. 領収書の内容を短く読み上げます。
5. 録音停止を押します。
6. 録音ファイルが保存され、最新の録音として表示されることを確認します。

読み上げ例:

```text
2026年5月31日、スターバックス、コーヒー代、580円、会議費
```

## 5. 文字起こし/AI整形

1. 録音後、文字起こしまたはAI整形を実行します。
2. 音声内容から日付、支払先、摘要、金額、勘定科目などが抽出されることを確認します。
3. 結果が不自然な場合は、設定画面のプロバイダー/APIキー/STT設定を確認してから再実行します。

テスト入力欄がある場合は、録音の代わりに手入力テキストからAI整形を確認しても構いません。

## 6. 最新の撮影画像/最新の録音の確認

入力画面でカメラを使う場合:

1. Windowsのカメラ許可が出た場合は許可します。
2. カメラプレビューが表示されることを確認します。
3. 領収書を撮影します。
4. 最新の撮影画像として表示されることを確認します。

録音後は、最新の録音が画面に表示され、再利用できる状態になっていることを確認してください。

## 7. レビュー画面での確認・修正

レビュー画面で作成されたレコードを確認します。

確認する項目:

- 日付
- 支払先
- 摘要
- 金額
- 勘定科目
- 税区分や補助項目がある場合はその内容

誤りがある場合は画面上で修正し、保存できることを確認してください。

## 8. 辞書の確認・追加

設定画面または辞書関連の画面で、登録済み辞書を確認します。

テストとして、勘定科目または摘要マッピングを1件追加してください。追加後、同じ支払先や摘要に対してAI整形またはレビュー時の候補が期待どおりになるか確認します。

個人情報や実在の取引先名を残したくない場合は、テスト用の名前を使ってください。

## 9. CSV出力

1. エクスポート画面を開きます。
2. CSV出力を実行します。
3. 保存ダイアログが開くことを確認します。
4. 任意のローカルフォルダに保存します。
5. CSVを開き、レビュー画面で確認した内容が出力されていることを確認します。

実データを使ったCSVは共有しないでください。共有が必要な場合は、テスト用データだけにしてください。

## 10. 終了後に共有してほしい確認結果

テスト後、次を共有してください。

- 成功した確認項目
- 失敗した確認項目
- 失敗時の実行コマンド
- エラー全文または画面上のエラーメッセージ
- Windowsのバージョン
- `node -v`
- `npm -v`
- `rustc --version`
- `cargo --version`
- clone先のパス
- 修正したファイルがあればその一覧

## 11. データを残さない注意

次の情報はローカル専用です。Git、Codexのチャット、README、docs、Issue、Pull Request、スクリーンショットに残さないでください。

- 実APIキー
- 録音ファイル
- 領収書画像
- 個人名、取引先名、金額などを含む実データ
- CSV出力ファイル
- アプリの設定ファイル
- セッションデータ

Windowsでは、設定やセッションデータが `%APPDATA%\com.tak.receiptvoicecapture\` 配下に保存される場合があります。共有前に実APIキーや個人データが含まれていないか確認してください。
